# Deployment & Infrastructure

## Local — Docker Compose

`docker-compose.yml` (root) brings up the entire stack on one bridge network
(`referral-network`): PostgreSQL 15, Redis 7, Jaeger, Prometheus, Grafana, all 12
services, and the frontend. Service URLs are wired via env (e.g.
`AUTH_SERVICE_URL=http://auth-service:8081`). `JWT_SECRET` is passed to both
`auth-service` and `api-gateway` (they must share the HMAC key —
see [Auth & Security Architecture](./auth-security-architecture.md)).

**Host ports:** frontend `3002→3000`; gateway 8080; auth 8081; listing 8082; claim 8083;
payment 8084; user 8085; admin 8086; notification 8087; support 8088; analytics 8089;
audit 8090; orchestration 8091; postgres 5432; redis 6379; jaeger UI 16686;
prometheus 9090; grafana 3003.

PostgreSQL initializes from `migrations.sql/V1__complete_schema.sql` (mounted into
`docker-entrypoint-initdb.d`). See [Shared Data Model](./data-model.md).

## Kubernetes / Helm

`infrastructure/`:
- `helm/referral-marketplace/` — Chart + `values.yaml`, `values-dev.yaml`, `values-staging.yaml`.
- `kubernetes/{dev,staging,production}/` — raw manifests. Production has
  `00-namespace`, `01-secrets`, `02-configmap`, `03-api-gateway`, `04-auth-service`,
  `05-user-service`, and **`06-network-policies.yaml`** (default-deny ingress +
  gateway-only ingress to backends — the in-cluster half of the auth trust boundary).
  ⚠️ The manifest set is **incomplete** (not all 12 services have manifests yet);
  Deployments use the `app: <service-name>` label convention.

## Terraform

`infrastructure/terraform/` — modules `vpc`, `eks`, `rds`; environments for `aws`,
`azure`, `gcp`. Provisions the cluster + managed data stores.

## Observability

- **Prometheus** (`infrastructure/prometheus/prometheus.yml`) scrapes each service's
  `/actuator/prometheus`.
- **Grafana** for dashboards (admin/admin default in compose — change for real use).
- **Jaeger** for distributed tracing; W3C trace propagation, `X-Trace-ID` generated by
  the gateway's `TraceIdFilter` and threaded through all services.

## Known deployment gaps (from the audit)

- Secret manifests are git-tracked placeholder/plaintext (`kubernetes/*/secrets.yaml`
  is gitignored, but examples exist) → move to External/Sealed Secrets.
- NetworkPolicies exist only under `production/` → mirror to dev/staging and validate on
  a NetworkPolicy-enforcing CNI.
- Actuator exposure should be locked down in prod; gitleaks belongs in CI.

See [CI/CD Pipelines](./cicd-pipelines.md) for how images are built and environments
are promoted, and the
[Production Readiness Audit](../../.claude/context/PRODUCTION_READINESS_AUDIT.md) for the full gap list.
